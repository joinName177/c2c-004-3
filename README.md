# c2c-004 · 行李箱空间规划师

Vue 3 + TypeScript + Vite 纯前端行李打包工具。录入行李箱和物品后，可比较“精简版、舒适版、购物版”三种装箱策略，通过俯视图、侧视图、重量/空间指标和风险清单理解摆放结果，并打印装箱清单。

## 功能

- 行李箱长宽高与承重配置
- 物品清单、类别、尺寸、重量、优先级和必带标记
- 相机包、收纳盒等容器的外尺寸、内尺寸、自重与多层归属
- 先按容器内尺寸规划子物品，再以容器外尺寸和实装重量参与外层装箱
- 容器内部待处理物品需明确移出后才独立参与外层装箱；归属循环（自身或下级）会被拦截
- 确定性三维长方体装箱、旋转与碰撞检测
- 三套方案对比、双投影视图联动和逐层打开容器摆放图
- 超重、空间紧张、尺寸越界、必需品遗漏、容器未装入、易碎品受压和重心风险
- 移动或删除容器前预览受影响内容，确认后重新计算并保存归属关系和各层结果
- localStorage 本地保存与打印分层清单

## 分层架构

- `src/core`：领域模型、几何、装箱算法、策略编排与风险规则
- `src/ports`：规划仓储与打印接口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、组件与原生 CSS

依赖只由 UI/适配器指向端口和核心层；核心层不读取浏览器状态，可独立测试。

## 装箱算法

引擎为每件物品枚举唯一的轴向旋转，并按“低层 → 靠后 → 靠左”的候选角点尝试放置。每次放置都检查箱体边界、长方体相交、方案承重和预留体积。它是快速、可解释的启发式算法，不保证数学意义上的全局最优，也不模拟软质物品压缩。

容器会递归形成规划树：子物品和下级容器先按当前容器的**内尺寸**装箱；容器被当前层装入后，才以自身**外尺寸**、容器自重与内部实装重量进入上一层。容器内放不下的对象保留为该层待处理项，不会被偷偷拿到外层；只有用户显式移出后才改变归属并参加外层装箱。必带检查沿整棵归属树计算，只要必带叶子所在的任何一层未装入，就会标记整趟行李不齐全。

## 开发与测试

```bash
npm install
npm run dev
npm test
npm run build
```

数据只保存在当前浏览器的 `localStorage`，不会上传。

## Docker

```bash
docker compose up --build
```

访问 [http://localhost:8104](http://localhost:8104)。生产镜像由 Node 20 构建并由 Nginx 1.27 托管，已配置单页应用回退。
