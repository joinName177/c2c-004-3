# c2c-004 · 行李箱空间规划师

Vue 3 + TypeScript + Vite 纯前端行李打包工具。录入行李箱和物品后，可比较“精简版、舒适版、购物版”三种装箱策略，通过俯视图、侧视图、重量/空间指标和风险清单理解摆放结果，并打印装箱清单。

## 功能

- 行李箱长宽高与承重配置
- 物品清单、类别、尺寸、重量、优先级和必带标记
- 相机包、收纳盒等容器的外尺寸/内尺寸、归属树与逐层装箱规划
- 容器先按内尺寸摆放子物品，外层只按外尺寸摆放容器；外层重量为“容器自重 + 实际装入内容”，子物品不会重复计重
- 容器内放不下的内容保留为本层待处理项，只有明确移出容器后才独立参与外层装箱
- 确定性三维长方体装箱、旋转与碰撞检测
- 容器防自装/防下级回套；可逐层打开摆放图、移动或删除前预览受影响内容
- 三套方案对比和双投影视图联动
- 超重、空间紧张、尺寸越界、容器内必需品遗漏、易碎品受压和重心风险
- localStorage 本地保存（含归属关系与各层规划结果）与打印清单

## 分层架构

- `src/core`：领域模型、几何、装箱算法、策略编排与风险规则
- `src/ports`：规划仓储与打印接口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、组件与原生 CSS

依赖只由 UI/适配器指向端口和核心层；核心层不读取浏览器状态，可独立测试。

## 装箱算法

规划从最深层容器开始：每个容器使用其内尺寸摆放直接子物品/子容器；子容器携带的重量只包含容器自重和该容器内已实际放入的内容，未放入的内容保留在原容器待处理，不提升到父层或行李箱。外层方案随后只处理根物品与闭合后的容器外尺寸，因此任一实体的重量只在其直接父空间计入一次。

每个空间仍为每件可摆放物件枚举唯一的轴向旋转，并按“低层 → 靠后 → 靠左”的候选角点尝试放置。每次放置都检查空间边界、长方体相交、方案承重和预留体积。它是快速、可解释的启发式算法，不保证数学意义上的全局最优，也不模拟软质物品压缩。

## 开发与测试

```bash
npm install
npm run dev
npm test
npm run build
```

数据只保存在当前浏览器的 `localStorage`，不会上传。

## Docker

```bash
docker compose up --build
```

访问 [http://localhost:8104](http://localhost:8104)。生产镜像由 Node 20 构建并由 Nginx 1.27 托管，已配置单页应用回退。
